## Projects

### 🛡️ CrashFix

**Minecraft Anti-Crash & Packet Security**

CrashFix is a security-focused Minecraft plugin designed to protect servers against malicious packets, protocol abuse and crash exploits.

The project focuses on:

- Packet-level validation
- Netty pipeline protection
- Packet rate limiting
- Malformed packet detection
- Exploit mitigation
- Protocol-specific security checks
- Performance-oriented detection

> CrashFix has been used to protect Minecraft networks against packet-based crashes and exploits.
